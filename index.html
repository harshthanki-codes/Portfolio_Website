06 // Engineering Philosophy

How I Think About Intelligent Systems & Engineering

I am a Python Developer & AI/ML Engineer based in Ahmedabad, India. My work focuses on custom LLM automation pipelines, scalable enterprise operations architectures, and resilient enterprise backend services.

Rather than treating AI as a shallow API wrapper, I focus on the hard engineering questions: How do we fine-tune a 7B model so it runs locally at zero marginal cost? How do we build a 7-tier failover DAG so a voice-to-order pipeline never drops a customer transaction? How do we seal endpoint DNS loopholes so security cannot be bypassed with a browser toggle?

My long-term ambition is to build deep-tech AI software that solves foundational operational bottlenecks. I prioritize empirical evaluation suites, measurable latency SLAs, and clean architectural separation of concerns over superficial trends.

01 //Zero Marginal Token Cost

Cloud APIs are great for prototyping, but enterprise unit economics demand on-premise open-weights intelligence. Fine-tuning models on domain datasets turns recurring expenses into an owned high-margin asset.

02 //Fault-Tolerant by Architecture
7-Tier Failover Mesh

Single-provider LLM pipelines fail in production. Whether it is an unexpected HTTP 429 rate limit or an upstream outage, systems must gracefully degrade across multi-tier failovers down to deterministic cached fallbacks.

An AI feature that freezes the client UI or runs uncontrolled N+1 database queries is broken. Background workers, asynchronous queues, and indexed compound lookups are non-negotiable standards.
